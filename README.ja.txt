ランニングIT
-------

から始める Start menu、またはデスクトップのショートカットから、インストーラを1つ尋ねた場合。

ゲートウェイを起動し、 DXKeeper, DXView, Pathfinder どんな順序でもあなたのロガー。 ゲートウェイはそれぞれに繋がります。

あなたの設定は、Windowsレジストリに住んでいます, 同じキーの下に使用VB6ゲートウェイ, ので、古いバージョンからの設定は、自身で持ち運びます.

ふりがな DXLab Launcher ゲートウェイを他のゲートウェイと一緒に起動できます DXLab プログラム;
「非特定」を参照してください。DXLab Launcherのヘルプでアプリケーションの名前のトピック。

変更・削除 QSOs トグルをアップ
------------------

スイッチの前にこれを読んで下さい Upload to eQSL.cc, Upload to LoTW または Upload to Club
Logお問い合わせ

これらのトグルは、 DXKeeper アップロードする QSO ログブックに記録されるとすぐにログブックへ。 分離して、ゲートウェイは編集と削除をサポート
QSOs: ロガーが変更を送信すると、ゲートウェイは削除します QSO から DXKeeper そして修正された1つを、従って記録します DXKeeper
単一の「置換」操作はありません。

これらの2つの特徴はうまく組み合わせず、ゲートウェイも結合しません。 DXKeeper それらを作ることができます。
既に削除したアップロードはリコールできません。 LoTW 特に削除する方法はありません QSO お問い合わせ お問い合わせ QSO
アップロードし、編集された葉ORIGINALは、 LoTW これまでは、それを交換するのではなく、逆に修正を加えた。 ツイート QSO
アップロードして削除された滞在 LoTW 自分のログからなくなってしまった後。

ゲートウェイが編集と削除をサポートする前に、これは発生できません。 QSO ログアウトしたのは最終です。

ITについて

簡単な回答と、著者が使用する1つは、コンテスト中に3つのアップロードトグルをOFFに残し、アップロードからアップロードすることです。 DXKeeper
ログが終了したら、任意の修正が行われました。 DXKeeper ログ全体を1つだけ簡単にアップロード QSO、そしてそれによって正しいために残っていません。

必要に応じてそれらを切り替えます - ゲートウェイは、一度警告し、それが言われているようにします -
しかし、後で修正は、オンラインログブックをクリーンに到達しないことに注意してください。

これは適用されません Query Callbook または Lookup previous QSOs. 読むだけ。
